# Solution: innova-canvas

Contiene la Canvas App INNOVA con todas sus pantallas:

- Pantalla de Inicio personalizada por rol
- Pantalla #1 Solicitante
- Pantalla #2 PMO Evaluación
- Pantalla #3 TI
- Pantallas #4 y #6 Jefatura
- Pantalla #5 PMO Ejecución
- Pantalla #7 Cotizaciones
- Pantalla #8 Gerencia
- Pantalla del Comité
- Pantalla "Mis Solicitudes" (tracking)
- Pantalla Administrador

Componentes compartidos (header, navegación, cards de indicadores) viven en `Component` library dentro de la app.

Ver `docs/conventions/power-fx-style.md` para reglas de Power Fx.
