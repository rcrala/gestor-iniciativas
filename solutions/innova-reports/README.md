# Solution: innova-reports

Contiene los artefactos de Power BI:

- Dashboard ejecutivo (`.pbix`) con KPIs en tiempo real
- Paginated Reports para exportación a Excel, PDF, CSV
- Modelos de datos y medidas DAX
- Configuración de RLS de Power BI espejo de Dataverse

Los archivos `.pbix` se mantienen versionados en git con Git LFS si superan 50MB.
