### Added
- **Power BI dataset semantico en TMDL (formato git-friendly)**: nuevo proyecto PBIP en [`solutions/innova-reports/innova-dataset/`](solutions/innova-reports/innova-dataset/) con el modelo semantico completo de INNOVA en formato TMDL (Tabular Model Definition Language) — texto plano, code-reviewable, replaza `.pbix` binario para la parte de modelo. Modelo estrella con `iniciativa` como fact y 5 dimensiones (empresa, centroCosto, departamento, estados, Calendar). 17 archivos: `innova-dataset.pbip`, `SemanticModel/definition.pbism`, `definition/model.tmdl`, `database.tmdl`, `relationships.tmdl`, `cultures/es-CR.tmdl`, 6 archivos `tables/*.tmdl`. **8 medidas DAX**: Total Iniciativas, Monto Estimado Total, Ahorro Anual Total, ROI Promedio Ponderado (formula correcta: `(sum_ahorro - sum_monto)/sum_monto*100`, no average de columnas), Iniciativas Aprobadas, Tasa de Aprobacion, Iniciativas Canceladas, Iniciativas Multi-Empresa. **7 relaciones** declaradas (3 lookups + 2 a Calendar con la fechaCreacion activa y fechaSolicitud inactiva via USERELATIONSHIP, 2 entre dims). Calendar dim calculada (2024-2030, mes/trimestre/anio en es-CR). Tabla `estados` tambien calculada con los 17 codigos del optionset pas_iniciativa_estado mapeados a label + orden + categoria (Inicial/Evaluacion/Estimacion/Cotizacion/Aprobacion/Comite/Terminal). Conexion via `OData.Feed` al environment DEV (URL hardcoded; refactor a Power Query parameter pendiente para multi-env). Report shell vacio (visuals los agrega el equipo de BI). README con instrucciones para abrir en Power BI Desktop 2024-04+. Limitaciones documentadas: sin RLS, sin multi-env parametrizado, sin visuals todavia. Validators repo PASS (0 errors)
